# Product run checklist

Before implementing a module:
- [ ] Module spec is APPROVED.
- [ ] Dependencies are complete.
- [ ] No unresolved product decision blocks behavior.
- [ ] Architecture stage has exact file plan.
- [ ] Design system requirements are known for UI work.
- [ ] Data/security impact is understood.
- [ ] Allowed/Forbidden files are explicit.
- [ ] Validation commands exist.
